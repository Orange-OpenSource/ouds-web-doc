Display property

Quickly and responsively toggle the display value of components and more with our display utilities. Includes support for some of the more common values, as well as some extras for controlling display when printing.

On this page

  • How it works
  • Notation
  • Examples
  • Clearfix
  • Hiding elements
  • Display in print

How it works

Change the value of the display property with our responsive display utility classes. We purposely support only a subset of all possible values for display. Classes can be combined for various effects as you need.

Notation

Display utility classes that apply to all breakpoints, from 2xs to 3xl, have no breakpoint prefix. This is because those classes are applied from min-width: 0; and up, and thus are not bound by a media query. The remaining breakpoints, however, do include a breakpoint prefix.

As such, the classes are named using the format:

  • .d-{value} for 2xs
  • .{breakpoint}:d-{value} for xs, sm, md, lg, xl, 2xl, and 3xl.

Where value is one of:

  • none
  • inline
  • inline-block
  • block
  • grid
  • inline-grid
  • table
  • table-cell
  • table-row
  • flex
  • inline-flex

The display values can be altered by changing the display values defined in $utilities and recompiling the SCSS.

The media queries affect screen widths with the given breakpoint or larger. For example, .lg:d-none sets display: none; on lg, xl, 2xl, and 3xl screens.

Clearfix

There's no more clearfix helper in OUDS Web as it's an outdated technique. Instead, use the display: flow-root utility, .d-flow-root. This forces a container element to create a new block formatting context without the clearfix. In the following example, without .d-flow-root, the wrapping div would not span around the buttons which would cause a broken layout.

<div class="d-flow-root bg-surface-status-info-emphasized p-xsmall">
  <div data-bs-theme="root-inverted">
    <button type="button" class="btn btn-default btn-on-colored-bg float-start">Example Button floated left</button>
    <button type="button" class="btn btn-default btn-on-colored-bg float-end">Example Button floated right</button>
  </div>
</div>

Hiding elements

For faster mobile-friendly development, use responsive display classes for showing and hiding elements by device. Avoid creating entirely different versions of the same site, instead hide elements responsively for each screen size.

To hide elements simply use the .d-none class or one of the .{xs,sm,md,lg,xl,2xl,3xl}:d-none classes for any responsive screen variation.

To show an element only on a given interval of screen sizes you can combine one .*:d-none class with a .*:d-* class, for example .d-none .md:d-block .xl:d-none will hide the element for all screen sizes except on medium and large devices.

Display in print

Change the display value of elements when printing with our print display utility classes. Includes support for the same display values as our responsive .d-* utilities.

  • .print:d-none
  • .print:d-inline
  • .print:d-inline-block
  • .print:d-block
  • .print:d-grid
  • .print:d-inline-grid
  • .print:d-table
  • .print:d-table-row
  • .print:d-table-cell
  • .print:d-flex
  • .print:d-inline-flex

The print and display classes can be combined.

Screen Only (Hide on print only)
Print Only (Hide on screen only)
Hide up to large on screen, but always show on print
<div class="print:d-none">Screen Only (Hide on print only)</div>
<div class="d-none print:d-block">Print Only (Hide on screen only)</div>
<div class="d-none lg:d-block print:d-block">Hide up to large on screen, but always show on print</div>
