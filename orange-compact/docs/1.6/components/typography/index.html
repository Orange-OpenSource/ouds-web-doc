Typography

Typography is a set of UI elements that structure and style text content, including headings, display text, body text, labels, and code, used to establish visual hierarchy and ensure consistent, accessible reading across OUDS Web.

Overview

Component types

  • Display

    Display is a UI element that styles typography for impactful content like landing pages, marketing campaigns, and key messages.

  • Heading

    Heading is a UI element that styles typography to structure content and define the hierarchy of information within an interface.

  • Body

    Body is a UI element that styles typography for common text content like paragraphs, descriptions, and informational messages.

  • Label

    Label is a UI element that styles typography for compact interface components such as buttons, form fields, badges, and other small elements.
  • Code
    Code is a UI element that styles typography for technical content like code snippets, commands, system values, and identifiers.

Approach

Typography elements are provided as components that include the font-family, font-size, line-height, letter-spacing, max-width, and for some of them, font-weight. However, certain elements can be modified using our utilities. Take a look at our font weight utilities, icon sizing utilities, color utilities, and the .mw-none class in width utilities.

Accessibility

To ensure accessibility, make sure you choose the HTML tags you use, based on their semantic meaning; whether it is a heading, plain text, or a snippet of code, you should not use the same tag, regardless of how it appears on screen. Each tag conveys its own semantic meaning, which is communicated to screen readers.

Display

Display is a UI element that styles typography for impactful content like landing pages, marketing campaigns, and key messages.

The display features large type sizes that capture attention and create strong visual emphasis. Variants automatically adjust across breakpoints to maintain a consistent visual hierarchy on all screen sizes. Use it sparingly to preserve its impact and effectiveness.

Display has three size levels: large, medium, and small. Each one sets font-size, and also line-height, letter-spacing, font-weight: bold, and max-width. Display uses the OUDS Web font stack.

Please note that:

  • You have to use the appropriate HTML tag to convey the right semantic meaning.
  • The .display-* classes are equivalent to the font size text utilities .fs-dl, .fs-dm, and .fs-ds, except for the font-weight.
  • If you want to get rid of the max-width, please use our .mw-none width utility.
  • You should not use any icon with our .display-* font sizes, because we prefer to keep the place for the text.

Heading

Heading is a UI element that styles typography to structure content and define the hierarchy of information within an interface.

The heading features multiple sizes options, to help users quickly understand the organization of a page or section. Variants automatically adjust across breakpoints to ensure optimal readability on all devices. Heading serve as the primary entry point for visual navigation.

All HTML headings, <h1> through <h6>, are available. Each one sets font-size, and also line-height, letter-spacing, font-weight: bold, and max-width. .h1 through .h6 classes are also available, for when you want to match the font styling of a heading but cannot use the associated HTML element. Heading uses the OUDS Web font stack.

Please note that:

  • You have to use the appropriate HTML tag to convey the right semantic meaning. A heading tag meaning is not reflected by the corresponding class on a <p> tag.
  • The heading tags and classes are equivalent to the font size text utilities .fs-hxl, .fs-hl, .fs-hm, .fs-hs, .fs-bl, and .fs-bm, except for the font-weight.
  • If you want to get rid of the max-width, please use our .mw-none width utility.
  • If you want to get rid of the margin-bottom, please use our .mb-none spacing utility.
  • You can easily add an icon with your headings using our heading icon size utilities.

Body

Body is a UI element that styles typography for common text content like paragraphs, descriptions, and informational messages.

The body features multiple size options, to allow content importance to be expressed while maintaining consistency. Variants automatically adjust across breakpoints to ensure optimal readability on all devices. Body prioritize readability and provide a comfortable reading experience.

Body text has three size levels: large (for emphasis), medium (default), and small (for supporting information). Each one sets font-size, line-height, letter-spacing, and max-width. Body has a font-weight: normal by default and it uses the OUDS Web font stack.

Please note that:

  • You have to use the appropriate HTML tag to convey the right semantic meaning, generally a <p>.
  • The .lead, <p> and .small or <small> texts are equivalent to the font size text utilities .fs-bl, .fs-bm, and .fs-bs.
  • You can use other font weights as needed through our font weight utilities.
  • If you want to get rid of the max-width, please use our .mw-none width utility.
  • If you want to get rid of the margin-bottom applied on <p> elements, please use our .mb-none spacing utility.
  • You can easily add an icon with your body texts using our body text icon size utilities.

Note

By default, body medium is set on the :root element, and the max-width property is applied to <p> elements.

Label

Label is a UI element that styles typography for compact interface components such as buttons, form fields, badges, and other small elements.

The label is non-responsive and maintains a fixed size across all breakpoints. This ensures visual consistency and predictable behavior within space-constrained UI elements. Labels are preferred when content is displayed within small components.

Labels have four size levels: xlarge, large, medium, and small. Each one sets font-size, line-height, letter-spacing, and max-width. Label uses the OUDS Web font stack.

Please note that:

  • You have to use the appropriate HTML tag to convey the right semantic meaning, generally a <p>.
  • You can use other font weights as needed through our font weight utilities.
  • If you want to get rid of the max-width, please use our .mw-none width utility.

Code

Code element is a UI element that styles typography for technical content like code snippets, commands, system values, and identifiers.

The code employs a monospace typeface to maintain character alignment and enhance the readability of structured content. Offered in one size, it ensures a uniform presentation of technical information across the product. Its application should be restricted to content that necessitates a precise code-like representation.

Use the <code> element to mark short code snippets within text. The <code> element uses the monospace code font stack and is styled to stand out from surrounding text.

For example, <section> should be wrapped as inline. 
For example, <code>&lt;section&gt;</code> should be wrapped as inline.
