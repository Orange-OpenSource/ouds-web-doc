Note

You can find here the iconography design guidelines.

You may use two types of icons in your projects, like in this documentation:

  • Project icons: As part of an eco-design approach, the icons from the Solaris icons library are not included in OUDS Web by default. You must select the icons you need and import them, preferably into an SVG sprite file. See using icons section for more technical information about the ways to import icons.
  • Component icons: Provided directly by OUDS Web, they are part of certain components, such as the breadcrumb separator or the list bullet. These icons are defined directly in our CSS stylesheet and integrated into OUDS Web.

While OUDS Web doesn’t include an icon set by default, Orange does have its own comprehensive icon library called Solaris. While most icon sets include multiple file formats, we prefer SVG implementations for their improved accessibility and vector support.

Solaris icons library is a growing library of icons that are designed by OUDS design team. It features an icon search tool based on categories and keywords, and allows icons to be downloaded in various formats for use in design and development. They are not open-source though and should only be used for Orange projects. Please refer to the icons license file for legal information.

Rendering

Icons are designed within a square layout to preserve consistency. Within this square, there exists a designated safety zone to guarantee that icons can be used in various sizes and contexts while maintaining alignment as intended by the designers. The dimensions of the icons encompass this safety zone, ensuring adaptability and consistency across diverse applications.

You can use the utility classes provided in the icons sizing utilities documentation to adjust the size of your icons according to your needs.

SVG sprite

This technique is the preferred choice for flexibility, performance and accessibility.

Using the Solaris icons finder, you can generate an SVG sprite, a single SVG file containing all your icons in <symbol> elements, and then insert an icon through a <use> element. With SVG sprites, you can benefit of the power of currentColor for easy coloring and theming.

Please note that if you experience a problem with a cropped SVG, we recommend using the .overflow-visible utility on the SVG to fix its rendering.

SVG sprite file example:

<svg xmlns="http://www.w3.org/2000/svg">
  <symbol id="settings" fill="currentColor" viewBox="0 0 1000 1000">
    <path d="..." fill-rule="evenodd"/>
  </symbol>
  <symbol id="trash" fill="currentColor" viewBox="0 0 1000 1000">
    <path d="..." fill-rule="evenodd"/>
  </symbol>
</svg>

SVG sprite usage:

<svg class="decorative-large-icon" aria-hidden="true">
  <use xlink:href="/orange/docs/1.6/assets/img/ouds-web-sprite.svg#settings" />
</svg>
<svg class="decorative-large-icon" aria-hidden="true">
  <use xlink:href="/orange/docs/1.6/assets/img/ouds-web-sprite.svg#trash" />
</svg>

To speed up loading, the SVG sprite file can be preloaded in the <head> of the page:

<link rel="preload" href="/path/to/your/sprite.svg" as="image" type="image/svg+xml" />

Icon font

Icon font is not the preferred solution. However, for websites needing more than 20 icons, you may consider using an icon font instead of an SVG sprite for eco-design reasons.

Using the Solaris icons finder, you can generate an icon font containing all your icons and use it like a classic font. Icons can be styled through CSS properties like font-size and color. Please keep in mind that adding or removing icons from the font afterward can be complicated.

<span class="si si-settings decorative-large-icon" aria-hidden="true"></span>
html

Heads up!

Note that with this technique, you cannot have multicolor icons, so you cannot render the warning icon.

CSS background image

CSS background icons should be used when you can’t or don’t want to refer to an external image, or if you want to include the icon in a CSS ::before or ::after pseudo-element. Be aware that you cannot provide an alternative text for assistive technologies, so use it wisely.

Technically, you should use the mask-image property instead of background-image to benefit from the coloring and theming system, by setting background-color property to currentcolor. You can use the SVG code within your CSS (be sure to escape any characters with our internal escape-svg() function). When no dimensions are specified via width and height on the <svg>, the icon will fill the available space. Mask images can also be styled through CSS properties like width or height. Note that the xmlns attribute is required.

Home 
<span class="icon-home decorative-large-icon"><span class="visually-hidden">Home</span></span>
html

Using:

site/src/scss/_component-examples.scss 
.icon-home::before {
  display: inline-block;
  width: 1em;
  height: 1em;
  vertical-align: bottom;
  content: "";
  background-color: currentcolor;
  background-size: contain;
  mask-image: escape-svg(url("data:image/svg+xml,<svg xmlns='http://www.w3.org/2000/svg' viewBox='0 0 24 24'><path d='M13.3 3.5a2 2 0 0 0-2.6 0L2.4 12H6v7.2A2 2 0 0 0 7.8 21h8.4a2 2 0 0 0 1.8-1.8V12h3.6zm.6 9.4v5.2H8.7a1 1 0 0 1-.9-.9V12H13a1 1 0 0 1 1 .9'/></svg>"));
}

Inline SVG

This technique should only be used if you have few icons to render, and if they are used only once in your website.

You can embed your icons directly within the HTML of your page (as opposed to an external image file). This way to use SVGs can benefit of the power of currentColor for easy coloring and theming.

<svg fill="currentColor" viewBox="0 0 24 24" class="decorative-large-icon" aria-hidden="true">
  <path fill-rule="evenodd" d="M17.4 9.6h-.6V9c0-2.64-2.16-4.8-4.8-4.8S7.2 6.36 7.2 9v.6H4.8v10.8a1.8 1.8 0 0 0 1.8 1.8h12.6V11.4a1.8 1.8 0 0 0-1.8-1.8M9 9a3 3 0 1 1 6 0v.6H9zm4.57 6.28a2 2 0 0 1-.7.7l.33 3.22h-2.4l.32-3.23a1.8 1.8 0 1 1 2.45-.7" clip-rule="evenodd"/>
</svg>

External SVG

You can use SVG through an <img /> tag when:

  • you only have few icons to render
  • you don’t need to change the icons colors. For that reason, we do not recommend to use that technique, so it won’t be documented here.

Accessibility

Note

For more details, Orange Accessibility Guidelines provides a deep-dive article regarding SVG accessibility.

Decorative icons

Purely decorative icons (like repeating information of an adjacent text) must be hidden to assistive technologies:

  • for <svg> or <span> tags, use the attribute aria-hidden="true"
  • for <img />, use an empty alt attribute
  • CSS background images are intended to be decorative

You should set decorative icon sizes in px so they do not scale with text zoom, leaving room for surrounding meaningful content.

Informative icons

If the icon is meaningful with no visible adjacent text, e.g. indication in a table or only content of a button, you have to provide an appropriate alternative text with the description of the icon or the description of the action triggered.

The best way to do this is to keep the icon hidden to assistive technologies (see above) and add a visually hidden label which will be perceived by assistive technologies, by using the .visually-hidden class. You can also use an aria-label on the containing interactive element to provide an accessible name. For external images within the <img /> tag, you can also fill the alt attribute directly.

Remember that you cannot use external images inside interactive elements because the color won’t change with the element’s status (hover, active, focus...), see External SVG image.

You should set informative icon sizes in rem so they scale with text zoom.

Colors

To color icons, you can:

  • use color utilities classes like .text-brand-primary, .text-disabled or .text-status-positive that change current color value.
  • specify a color using CSS variables like --bs-color-content-brand-primary, --bs-color-content-disabled or --bs-color-content-status-positive.

For SVGs (SVG sprites, inline SVGs or CSS mask image SVGs), the fill="currentColor" attribute is required on the <svg> or <symbol> tag, if you want to change the icons color on the fly (for example on hover): it will make the icon inherit color from itself or its parent containers. It is set on the icons downloaded from Solaris icons finder. For CSS mask image SVGs, the background-color: currentcolor CSS property should be set.

Status colors

Here are some examples of status color utilities and CSS variables designed to provide feedback or information to the user. The colors info, positive, warning, and negative are intended for use only with functional icons. The accent color is intended to highlight something and can be used with any icon. Note that, to ensure accessibility, the warning icon uses two different colors for its inner and outer shapes, so you cannot directly use the color utility or CSS variable; see the section on the accessible warning icon for more details.

See below some information about the normal contexts of use of these status colors.

Color utilityColor CSS variableContext of use
.text-status-info--bs-color-content-status-infoUse to communicate a feedback. It’s more important than a neutral color.
.text-status-positive--bs-color-content-status-positiveUse to communicate a positive action, a confirmation or a positive feedback.
NA--bs-icon-color-content-status-warning-external-shape and --bs-icon-color-content-status-warning-internal-shapeUse to display an information that requires more attention, or an action from the user.
.text-status-negative--bs-color-content-status-negativeUse to communicate something negative. It can be a destructive action, an error state, or a negative feedback.
.text-status-accent--bs-color-content-status-accentUsed to highlight or draw attention to a specific element.

Accessible warning icon

To ensure accessibility through sufficient contrast, OUDS provides a dedicated warning icon with two distinct colors for its external and internal shapes. This design choice enhances visibility and clarity, making it easier for users to recognize and understand warning messages.

Here is a SVG symbol to insert into your SVG sprite. It uses the CSS variables --bs-icon-color-content-status-warning-external-shape and --bs-icon-color-content-status-warning-internal-shape to color the external and internal shapes of the icon respectively, changing according to color mode. See below to know more about SVG sprites.
